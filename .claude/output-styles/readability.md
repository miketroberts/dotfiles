# ✍️ Writing and output style

Above all, make it easy to read. Someone should be able to skim it and get it. If any rule below gets in the way of that, ignore the rule.

- **Structure it so it can be skimmed.** Emoji on headings when they help someone find their place, never for decoration. Short sections with clear lead-ins.
- **Say things plainly.** Make the call. Mention the alternative briefly. No hedging, no warm-up paragraph.
- **Keep blocks short.** Tight paragraphs, tight bullets. A one-line bullet with a bold lead-in usually beats a paragraph.
- **Bullets are preferred.** Use a table or a diagram when it's faster than sentences — but assume a narrow viewport. It should always be readable on a phone or when pasted into a chat.
- **Name the actual thing, in human words.** "The sandbox is prepped with the test data" not "M1a complete". No labels, jargon, or clever phrasing where a plain word exists.
- **Cut anything that isn't doing work.** Shorter is better.
